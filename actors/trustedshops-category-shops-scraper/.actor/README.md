# Trusted Shops Category Shops Scraper

Find Trusted Shops merchants by category and market. Export shop names, descriptions, ratings, review counts, certification status, and public shop profile links.

## What data can you extract?

| Field | Type | Description |
| --- | --- | --- |
| `profileType` | String | Trusted Shops profile category for the merchant. |
| `accountName` | String | Trusted Shops account name for the merchant. |
| `tsID` | String | Trusted Shops merchant identifier. |
| `shopDescription` | String | Merchant description shown on Trusted Shops. |
| `shopName` | String | Public shop name shown on Trusted Shops. |
| `shopUrl` | String | Public merchant website URL. |
| `shopCategories` | Array\<Object\> | Trusted Shops categories assigned to the merchant. |
| `shopLogoUrl` | String | Merchant logo image URL. |
| `descriptionAutoGenerated` | Boolean | True when Trusted Shops generated the shop description automatically. |
| `averageRating` | Number | Average customer rating for the shop; scale follows Trusted Shops. |
| `reviewCount` | Integer | Number of customer reviews reported for the shop. |
| `certificationState` | Boolean | True when Trusted Shops marks the merchant as certified. |
| `profileUrl` | String | Trusted Shops merchant profile URL. |
| `contractStartDate` | Integer | Unix timestamp in milliseconds when the merchant contract began. |
| `input_category` | String | Category submitted to retrieve this shop profile. |
| `scraped_at` | String | UTC ISO 8601 timestamp when this dataset record was collected. |

## Use cases

- Ecommerce researchers can compare stores and review totals by category.
- Marketplace teams can find certified shops in selected country markets.
- Brands can map competitor stores and shop profile links.

## How to use

1. Add a Trusted Shops category path to `categories` for each search.
2. Choose a country market and set the starting page.
3. Set `maxPages` and `maxResults`, then export the shop records.

```json
{
  "categories": [
    {
      "category": "bucher"
    }
  ],
  "page": 0,
  "market": "DEU",
  "maxResults": 5,
  "maxPages": 1
}
```

## Input

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `categories` | Array\<object\> | Yes | Trusted Shops category URL paths such as buch, bekleidung, or sport. |
| `categories[].category` | string | Yes per entry | Category URL path \(e.g. bekleidung\). Use the Categories endpoint to get available values. |
| `categories[].page` | integer | No | Page number for pagination \(0-500\). Default: 0 |
| `categories[].market` | string | No | Market code filter \(DEU, GBR, AUT, CHE, NLD, ESP, ITA, FRA, BEL, POL, PRT\). Default: DEU |
| `page` | integer | No | Page number for pagination \(0-500\). Default: 0 |
| `market` | string | No | Market code filter \(DEU, GBR, AUT, CHE, NLD, ESP, ITA, FRA, BEL, POL, PRT\). Default: DEU |
| `maxResults` | integer | No | Maximum dataset items to save across this entire run. |
| `maxPages` | integer | No | Maximum pages to request for each batch entry. |

## FAQ

### Is scraping this information legal?

Rules depend on the source, location, data type, and intended use. Check applicable laws and source terms, and make sure your workflow follows privacy and data protection requirements.

### What limits apply?

Submit up to 100 batch entries per run. Use **maxResults** to cap saved items and **maxPages** to limit pages for each entry. Results also depend on source availability and your Scrappa API plan.

### Can I start runs through the Apify API?

Yes. Send a POST request to `https://api.apify.com/v2/acts/thescrappa~trustedshops-category-shops-scraper/runs` with your Actor input, or use an Apify client library. Read the output from the run dataset.

### Can I connect the results to other tools?

Yes. Apify integrations and APIs can pass dataset results to Make, Zapier, n8n, Google Sheets, and other data workflows.

### What happens when one input fails?

The Actor logs a short source error and continues with the remaining entries. Transient rate limits and gateway errors are retried; if every entry fails, the run reports an error.

### Where do I find a category path?

Use the category URL path shown by Trusted Shops. The API category listing can provide the available paths.
